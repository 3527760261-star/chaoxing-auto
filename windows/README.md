# 学习通自动助手 · Windows 版

只处理老师布置的虚拟题库作业 / 课程任务点；正式计分考试、补考、竞赛卷一律不代答。
不代签到；不绕过人脸识别、弹题、拖动验证、验证码；不索要、不保存账号密码。

## 铁律（违反就停手）

1. 只处理老师布置的虚拟题库作业 / 课程任务点；正式计分考试、补考、竞赛卷一律不代答。
2. **提交门（本次新规则，取代旧的「永不提交」）**：只有一份作业全部题目都有把握答案
   （不确定数 = 0）时才自动点提交；只要有 1 道不确定，就只点「暂时保存」，
   并在报告里列出不确定题号，绝不提交半份作业。提交前必须重载页面核对答案已保留。
3. 不代签到；不绕过人脸识别、弹题、拖动验证、验证码；平台要求人工确认时立刻停下。
4. 不索要、不保存账号密码，登录由用户本人在浏览器里完成。

## 新架构：脚本只做机械层，答案由外部传入

脚本不含任何模型调用配置，也不调任何模型接口，只做机械活：巡检、视频、
按答案填表、点「暂时保存」、重载核对、提交门判定、去重、写报告、定时巡检。

答案由操作者用的智能体提供：比如用仓库 `doubao/` 下的豆包提示词让豆包来答题，
再把答案写进 JSON 文件（格式见仓库根 `answers/README.md`），跑填答时传给脚本：

```
python do_homework.py --answers answers.json
```

接线在 `common/answer_provider.py`（`AnswerProvider` 协议、
`DictAnswerProvider`、`JsonFileAnswerProvider`），填答入口是
`common/homework.py` 的 `answer_assignment(page, assignment, provider)`。

**后果（请注意）：没有答案清单、也不接模型之后，脚本版不能再无人值守自动答题。**
答题必须靠智能体在场：智能体先答题、给出答案 JSON，脚本再按答案机械填答。
不给 `--answers` 时，`do_homework.py` 只做巡检与报告，不填题、不保存、不提交，
每份作业在报告里记为 `awaiting_answers`，并写明「待外部提供答案」。
定时值守（每小时一轮）同样只巡检，不会自动答题。

## 五分钟上手

1. 双击 `00_安装依赖.bat`（装 Python 依赖 + 跑自测）。
2. 复制仓库根的 `config.example.py` 为 `config.py`，再把里面的三门课换成你自己的课程号
   （courseid/clazzid/cpi 在学习通课程页 URL 里找，见仓库根 README「填你自己的课程信息」；
   只有课程、路径、浏览器与行为参数，不用再填任何模型配置）。
3. 双击 `1_登录.bat`，自己扫码登录学习通，勾「下次自动登录」。
4. 双击 `2_巡检.bat`，确认三门课的作业和任务点能读到。
5. 让智能体答题：用仓库根 `doubao/` 下的豆包提示词让豆包答题，
   把答案写进 JSON 文件（格式见仓库根 `answers/README.md`）。
6. 双击 `3_填答.bat`（或 `python do_homework.py --answers <答案 JSON>`），
   看报告：全部有把握才提交，有不确定只暂时保存。
   不给 `--answers` 时只巡检、不填题。
7. 需要长期值守：双击 `7_装成每小时计划任务.bat`（每小时跑一轮巡检；
   注意：值守轮次不自动答题，答题仍需智能体在场给答案）。

## 每个 bat 的作用

| bat | 作用 |
| --- | --- |
| `00_安装依赖.bat` | 找 Python → `pip install playwright` → 装 Edge 驱动 → 跑自测 |
| `1_登录.bat` | 扫码登录（勾「下次自动登录」），登录态进 `edge_profile` |
| `2_巡检.bat` | 只读巡检三门课 + 心理课任务点，不作答、不提交 |
| `3_填答.bat` | 巡检 → 按外部答案填答 → 提交门 → 报告（不给答案文件时只巡检） |
| `4_心理课视频.bat` | 心理课视频：原速、页面静音，96% 停，复核任务点 |
| `5_值守.bat` | 值守循环：每小时一轮巡检 → 填答（需答案文件） → 播放 |
| `6_自测.bat` | 不登录、不联网，mock 自测（提交门 / 答案提供方 / 状态去重） |
| `7_装成每小时计划任务.bat` | `schtasks` 注册，每小时跑 `watch.py --once` |
| `8_删除计划任务.bat` | 删除上面注册的计划任务 |
| `9_切换浏览器模式.bat` | profile / attach 切换，写 `settings.json` |

浏览器模式：`profile` 用独立档案；`attach` 克隆你的 Edge 档案到 `edge_clone` 再拉起，
绝不动原档案，跑 attach 前请先完全退出 Edge。

## 答案从哪来

脚本自己不答题。操作流程：

1. 巡检看到有未交作业（`2_巡检.bat` 或 `do_homework.py` 不给 `--answers` 的报告）；
2. 用仓库根 `doubao/` 下的豆包提示词，让豆包（网页版）答题；
3. 把豆包给的有把握的答案写进 JSON 文件（格式见仓库根 `answers/README.md`，
   没把握的题不要写进去，留空即可）；
4. 跑 `python do_homework.py --answers <答案 JSON>`，脚本按答案填答、
   暂时保存、重载核对，全部有把握才提交。

## FAQ

**没给答案文件（报告里是 awaiting_answers）**
`do_homework.py` 没收到 `--answers`，本轮只巡检、不填题，这是设计如此。
处理：按上面「答案从哪来」让智能体答题、写好 JSON，再跑
`python do_homework.py --answers <答案 JSON>`。

**答案文件读入失败**
`do_homework.py` 会直接报「答案文件读入失败」并停下。处理：检查文件路径对不对、
JSON 格式对不对（顶层必须是对象，见仓库根 `answers/README.md`）。

**登录失效（提示请先跑 1_登录.bat）**
重新双击 `1_登录.bat` 扫码登录，勾「下次自动登录」。登录态过期是正常的，
不要把账号密码告诉任何人、不要写进任何文件。

**9222 端口被占（attach 模式）**
先完全退出 Edge 再跑；还被占就查是谁在用 9222（`netstat -ano | findstr 9222`），
或在 `settings.json` 里把 `edge_port` 改成别的端口（如 9223）。

**保存后重载答案丢失**
程序会在重载后逐题核对，答案没保留就只暂时保存、不提交，并在报告里写明题号。
处理：先手动打开那份作业看答案在不在；如果页面本身就没保存住，重新传入答案后重跑一次
`3_填答.bat`；仍丢失就手动在浏览器里填好再保存。

**视频 d/t 未 +1（报告「第 x.x 章播放未计入」）**
程序不会重播（重播大概率也不计入）。处理：手动打开那一章看任务点状态；
如果是平台判定问题，手动看完该章；确认计入后，下次巡检任务点会正常 +1。
