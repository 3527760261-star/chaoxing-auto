# 答案提供方式：外部传入的 JSON 文件

脚本只做机械层，不做任何模型调用、不猜题。答案由操作者用的智能体提供：
比如用仓库 `doubao/` 下的豆包提示词让豆包来答题，再把答案写进一个 JSON 文件，
跑填答时传给脚本：

```
python do_homework.py --answers answers.json
```

不给 `--answers` 时脚本只做巡检与报告，不填题。

## JSON 文件格式

顶层是一个对象，键是题号（字符串），值是这道题有把握的答案：

```json
{
  "1": "B",
  "2": "AB",
  "3": "对",
  "4": "示例填空答案"
}
```

也可以用带 `certain` 的写法，`certain` 为 `true` 才算有把握：

```json
{
  "1": {"answer": "B", "certain": true},
  "2": {"answer": "C", "certain": false}
}
```

规则（由 `common/answer_provider.py` 的 `JsonFileAnswerProvider` 落实）：

- `"1": "B"` —— 字符串写法，表示有把握的答案，可以填。
  单选题 / 判断题填选项字母或「对 / 错」；多选题填多个字母，如 `"AB"`；
  填空题填空的内容，多个空用逗号分隔。
- `{"answer": "B", "certain": true}` —— 有把握，可以填。
- `certain` 为 `false`（或缺失）、答案为空字符串的题 —— 判不确定，留空。
- 文件里没有的题 —— 判不确定，留空。
- 文件不存在、不是合法 JSON、顶层不是对象 —— 构造时直接抛错，
  `do_homework.py` 立即停下，不静默跳过。

## 例子（假题号，仅示意格式）

```json
{
  "1": "B",
  "2": {"answer": "AB", "certain": true},
  "3": {"answer": "C", "certain": false},
  "4": "对"
}
```

上面这份答案：1、2、4 题有把握可以填；3 题没把握，留空。
只要有 1 道不确定，提交门就不通过，整份作业只点「暂时保存」，绝不提交。

## 铁律

- 只做老师布置的虚拟题库作业；正式计分考试、补考、竞赛卷的题不要做、不要答。
- 没把握的题留空，只点「暂时保存」，绝不提交半份作业。
- 答案文件只放本机，不要提交进仓库（它不在仓库里，只是一份运行输入）。
